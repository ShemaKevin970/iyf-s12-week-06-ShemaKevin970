# Week 6 - Weather Dashboard

Asynchronous JavaScript project using OpenWeatherMap API.

## Live Demo
https://shemakevin970.github.io/iyf-s12-week-06-ShemaKevin970

## Features
- Search by city (button or Enter)
- Shows temperature (°C), description, feels like, humidity, wind, pressure
- Loading state while fetching
- Error message for unknown city / no internet
- Last 5 searches saved in localStorage, click to search again

## Tech
- HTML, CSS, JavaScript
- async/await + try/catch + response.ok check
- OpenWeatherMap API

## Setup
1. Get a free API key from OpenWeatherMap
2. Copy `config.example.js` to `config.js`
3. Put your key in `config.js`
4. Open `index.html`
